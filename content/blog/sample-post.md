# Welcome to My Blog

This is a sample blog post to demonstrate the functionality of your new Hugo website. You can use this as a template for future posts.

## Getting Started

To create a new blog post, use the Hugo command:

```bash
hugo new content blog/your-post-title.md
```

## Writing Content

You can write your content in Markdown, which supports:

- **Bold text**
- *Italic text*
- `Code snippets`
- [Links](https://example.com)
- Lists
- And much more!

## Code Blocks
